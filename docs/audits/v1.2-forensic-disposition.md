## CLI-001 decision

The audit found that operational `index` and `db-info` remain human-only while most analytical
commands support JSON. That inconsistency is reproducible, but it is an automation ergonomics issue,
not an analytics or daily-use defect. No concrete v1.2 automation consumer defines the required
schema version, stable keys, or failure semantics. Adding an ad hoc shape immediately before release
would create a public compatibility obligation without evidence that the shape is sufficient.

`CLI-001` is therefore **DEFERRED TO v1.3+**. It remains a backlog item conditioned on a defined
consumer and versioned contract. No production code or empty implementation commit was created.

## Conservative semantics

No confidence threshold was loosened for Git provenance, task taxonomy, outcomes, token lineage, or
event provenance. v1.2 improves normalization, diagnostics, evidence decomposition, and incremental
execution while retaining explicit UNKNOWN, LOW, ambiguous, omitted, and unavailable states.
