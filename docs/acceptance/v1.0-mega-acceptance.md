## Analytics correctness

### Indexing and additive invariants

The 240-session synthetic acceptance corpus produced 239 indexed sessions and one deliberately
missing rollout. An immediate unchanged pass returned 239 unchanged, one skipped, and zero
failures. After exactly one rollout mutation, exactly one session updated and 238 remained
unchanged. The synthetic source hash did not change.

Observed rollout totals remain individual-session telemetry. Additive totals use reconciled local
contributions: only exact inherited or replayed ancestor baselines are deducted. Independent child
activity remains additive, siblings do not erase one another, nested lineage is handled, missing
token data remains unavailable, and ambiguous lineage is not guessed away.

For the synthetic selection, reconciled usage was 318,539 tokens from 333,683 observed tokens;
15,144 were confidently identified as inherited/replayed. Repository, model, day, and week group
sums each equaled the same 318,539 global total.

### Event and prompt provenance

Synthetic parent replay, independent children, siblings, nested lineage, ambiguity, missing data,
and cyclic/malformed topology tests passed. Physical observations remain distinct from originated
events. Parent replay does not become child origin; independently repeated child commands remain
child-originated.

Logical prompt IDs, replay deduplication, English, Traditional Chinese, mixed-language and quoted
FTS queries, long prompts, redaction, stable IDs, and filters passed. A bounded real search used a
non-sensitive generic term; only its result count/schema was inspected for acceptance and no prompt
body is recorded here.

### Commands, Git, outcomes, and tasks

Originated command/tool category totals reconciled. Replayed parent commands were excluded from
additive execution counts, while independent child executions remained counted. Secret-like and
heredoc fixture content stayed bounded/redacted. Executable and test-scope normalization tests
passed.

Synthetic Git tests covered stable repository identity, worktrees, detached HEAD, missing remotes,
moved/deleted repositories, concurrent sessions, and inherited evidence. Parent Git evidence alone
never created a HIGH-confidence child association.

Outcome and task tests covered success, recovery/failure, abort, research/status, review-only child,
insufficient evidence, and the documented action/domain taxonomy. Inherited outcome or intent
evidence did not independently classify a child. UNKNOWN and low-confidence results remained
explicit; thresholds were not weakened for better-looking coverage. Prompt-pattern correlations
remained descriptive, reported sample sizes, and made no causal or quality-score claim.

## Known limitations

- Codex local storage is undocumented and can drift; unknown fields/events require continued
  explicit capability and coverage diagnostics.
- Token lineage is deliberately conservative: 22 of 29 real child threads remained ambiguous, and
  their observed contribution was not guessed away.
- Local token telemetry does not reproduce a documented OpenAI billing/quota algorithm.
- Git attribution is conservative; most real candidates were LOW confidence and remain candidates,
  not confirmed associations.
- Outcomes and task classifications are heuristic and evidence-bounded. UNKNOWN and low confidence
  are expected states, not zeros.
- Tool-result linkage is incomplete for some source records, so result-derived failure coverage is
  explicit rather than universal.
- Relative time windows move with command execution time. Calendar dashboard periods and rolling
  CLI durations are intentionally different selections.
- Dashboard mobile visual quality and remote CI execution were not tested in this local acceptance.
- No public push, tag, release, or package publication occurred.
